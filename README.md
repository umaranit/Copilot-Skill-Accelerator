# 🚀 Copilot Skill Accelerator & Framework

**A professional foundation for specialized AI Agent Skills.**

This repository provides an automated way to inject expert-level Agent Skills into any project. While we provide "out-of-the-box" skills for Code Review and Linting, this toolkit is designed to be **extended and customized** by your team to fit your unique proprietary workflows.

---

## 🛠️ Quick Start
1. **Install:** `npx github:YOUR_USER/YOUR_REPO`
2. **Configure:** Edit the generated `skill-config.json`.
3. **Use:** Check the [Cheat Sheet](./CHEATSHEET.md) for trigger commands.

---

## 🎨 Built for Extensibility
We provide the foundation; you provide the secret sauce. 

* **Customize Rules:** Use `skill-config.json` to tell our skills about your specific tech stack.
* **Add New Skills:** Simply add a new folder to `.github/skills/` following our [Extension Guide](./EXTENDING_SKILLS.md).
* **Automate with Scripts:** Link your internal CLI tools to Copilot by placing them in a `scripts/` folder.
